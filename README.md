
# 🧬 Skin Cancer Detection Using Interpretable Deep Learning: A Comparative Analysis of CNN Architectures

**Conference Paper | LNNS, Springer (2026)**
📍 *International Conference on Computer Vision and Robotics (CVR 2025)*

🔗 **Paper Link:** [https://link.springer.com/chapter/10.1007/978-3-032-14038-8_7](https://link.springer.com/chapter/10.1007/978-3-032-14038-8_7)

## 📌 Overview

This project explores the application of **deep learning and explainable AI (XAI)** techniques for automated skin cancer detection. The goal is not only to achieve **high diagnostic accuracy**, but also to improve **model interpretability**, a critical requirement for real-world clinical adoption.

We perform a **comparative analysis of multiple CNN architectures** and integrate interpretability methods to visualize and explain model predictions.

---

## 🎯 Objectives

* Compare state-of-the-art CNN architectures for skin lesion classification
* Evaluate models using robust performance metrics
* Improve transparency using explainable AI techniques
* Deliver a deployable, clinician-friendly web-based solution

---

## 🧠 Models Evaluated

The following **8 CNN architectures** were implemented and benchmarked:

* Xception
* ResNet50
* AlexNet
* EfficientNetV2L
* MobileNetV2
* DenseNet121
* DenseNet201
* VGG16

---

## 📊 Evaluation Metrics

Models were evaluated using standard classification metrics:

* **Accuracy**
* **Precision**
* **Recall**
* **F1-score**

---

## 🔍 Explainability & Interpretability

To address the black-box nature of deep learning models, we integrated:

* **Grad-CAM** – visual heatmaps highlighting influential regions
* **LIME** – local, instance-level explanations for predictions

These techniques provide **visual and interpretable insights** into model decision-making, increasing trust and clinical usability.

---

## 🏆 Key Results

* **Xception** achieved the best performance with:

  * **95.30% test accuracy**
  * **95% F1-score**
* **EfficientNetV2L** and **DenseNet variants** showed competitive accuracy and strong generalization
* Interpretability methods consistently highlighted medically relevant lesion regions

---

## 🌐 Web Application

A **web-based application** was developed to:

* Upload and analyze skin lesion images
* Display model predictions
* Visualize Grad-CAM and LIME explanations

This bridges the gap between **research and real-world clinical usage**.
